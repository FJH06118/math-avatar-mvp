# 产品需求摘要

> 本文是跨会话使用的精简产品入口，依据当前代码和
> `docs/product/PPT-Digital-Human-Video-PRD-v1.0.md` 整理。详细需求仍以原始 PRD
> 为准；实现完成度以代码和 `docs/STATUS.md` 为准。

## 产品目标

把教师已有的 PPT 课件转换为可审核、可修改、可复现的中文 2D 卡通数字人讲解视频，尽量保留原课件的版式、公式、图表和教学信息。系统应让教师在生成前检查每页内容、讲稿、推导和呈现方式，在生成后获得可播放的视频、字幕及可定位的问题报告。

核心价值：

- 降低从课件到授课视频的制作成本。
- 让讲稿、公式推导和视觉叠加在生成前可人工把关。
- 让每次生成的输入、版本、任务步骤和输出可追踪、可重试。
- 保证原 PPT 页覆盖、媒体可播放和关键内容不被数字人遮挡。

## 目标用户与用户流程

广义用户是需要把结构化课程课件转成讲解视频的教师、教研/培训团队和知识内容创作者。2026-08-02 已确认首发评测以高等数学优先、首发用户为仅本机/测试环境的内部单用户；跨学科 Contract 保持通用。账号体系与团队协作方式仍待后续产品确认。

标准流程：

1. 新建项目，上传 PPT/PPTX 课件；`.pptx` 是主格式，旧 `.ppt` 文件先由隔离的 LibreOffice 流程转换为 `.pptx`。
2. 系统检查文件类型、完整性和页数，解析文本、图片、表格、备注与公式候选，并生成每页原图。
3. 系统完成页面分类与置信度判断；课程导演 Agent 根据课件生成结构化教学目标、讲稿、推导步骤、场景和叠加计划。
4. schema 与规则检查通过后，用户逐页审核、编辑、跳过或锁定内容，并配置数字人、声音及字幕。
5. 用户试听音频、预览关键帧，确认后显式批准并提交生成任务。
6. 系统生成最终语音和字幕，按页渲染原课件与受控叠加内容，再合成视频。
7. 系统完成媒体解码、页面覆盖、遮挡、静音/黑帧和时长等验证。
8. 用户查看失败定位或预览结果，按失败步骤重试，最终下载视频、字幕和版本化项目资料。

## MVP 范围

- 项目列表、新建项目和课件上传。
- PPTX 安全校验、`.ppt` 安全转换、解析、页数确认和逐页原页预览；默认输入上限为 100 MB、100 页。
- 每页文本、图片、表格、备注和公式的结构化结果；公式按 OMML、可识别文本、数学 OCR、保留原图和人工确认的顺序处理。**图片公式 OCR 已于 2026-08-04 经用户批准从 Web MVP 延期**（`DECISIONS.md` D-27）。
- 一个模块化课程导演 Agent；PPT 解析、TTS、渲染和媒体检查保持确定性。多模态 Provider 的支持声明按供应商逐个记录证据，见 [`PROVIDER_EVIDENCE.md`](PROVIDER_EVIDENCE.md)（七类 adapter 已实现，真实账号仅 DeepSeek 在本机实测）。
- 每页结构化教学目标、讲稿、公式推导、场景/叠加计划与置信度的人工审核和修订。
- 逐页编辑、跳过、锁定与单页重生成。
- 2D 半身卡通数字人、简化口型、声音、语速、字幕与基础教学视觉设置。
- 明确的审核批准门禁。
- 最终音频驱动的中文 TTS、SRT 字幕、原 PPT 页与数字人叠加；首版为 16:9、1920×1080 或 1280×720、25/30 fps、H.264/AAC、`yuv420p`、Fast Start。
- 可持久化的任务和步骤状态、取消、失败定位、失败步骤重试及最终下载。
- 输入版本、提示词/模型、模板、渲染参数和输出哈希等复现信息。

当前代码已实现前端 Mock 交互、真实产品纵切（BFF/Hono/PostgreSQL/Worker）与独立后端 CLI 原型；两条链并存，上述列表仍不是"全部已完成"的声明。

## 非目标

- 完整复现 PowerPoint 内置动画、宏、插件或所有复杂 SmartArt。
- 默认重做整页课件视觉设计；整页重设计必须由用户明确授权。
- 保证任意学科知识、任意公式识别和任意推导永远正确。
- 实时直播或实时数字人驱动。
- 写实 3D 数字人和完整非线性视频编辑器。
- 在 MVP 内支持任意用户代码、脚本、HTML、Shell 或 FFmpeg 命令执行。
- 在产品尚未确认前承诺团队协作、计费、品牌模板、背景音乐或 9:16/1:1 多画幅交付；这些是待确认项，而不是永久排除项。

## 验收标准

### 课件与审核

- 支持中文文件名的有效 PPTX；损坏、加密、超限或不支持的文件得到可操作错误。
- 解析页数与源文件一致；文本/图片提取准确率目标不低于 95%。
- 每个非跳过页面至少完整出现一次，使用 `contain` 适配、不裁切，连续展示不少于 1.5 秒；页面覆盖率为 100%。
- 标题、公式、图表、关键文本和字幕安全区不被数字人或叠加内容严重遮挡。
- Agent 输出通过版本化 schema 验证；首次结构化成功率目标不低于 90%，修复后不低于 99%。
- 用户修改使用修订号保护，生成时使用用户最后批准的版本，不得被后台结果静默覆盖。

### 音视频与交付

- 每段语音和字幕可解码、时序有效，语音失败不会被当作静音成功。
- 最终 MP4 为 1920×1080 或 1280×720、25/30 fps、H.264 视频、AAC 音频、`yuv420p`、Fast Start，可正常播放、拖动和完整解码。
- ffprobe、全量解码、页面覆盖、遮挡、字幕、黑帧、静音、时长和哈希检查均通过后才可交付。
- 候选视频和音频可解码率为 100%，字幕时间轴来自最终音频；至少抽检三类播放器。
- 同一页或步骤失败时可以定位并只重试失败步骤及被其影响的后续步骤。
- 浏览器只能得到稳定资源 ID 和受控 HTTP/签名 URL，不得得到服务端绝对路径、存储键、密钥或堆栈。

### 可用性

- 正常路由可到达上传、解析、审核、生成和结果页面。
- 初始、加载、空、成功、失败、重试和取消状态在适用流程中都有明确反馈。
- 中断或刷新后，真实任务可以从持久状态恢复，而不是依赖页面计时器推测进度。

## 当前实现与需求的主要差距

> 2026-10 修正（M0 文档真相）：本节此前描述的是 2026-08-04 之前的 Mock/CLI 阶段，
> 与当前代码冲突。以下按代码事实重写；完成度仍以 `docs/STATUS.md` 与
> `docs/CURRENT_TASK.md` 为准。

- 页面**默认仍是浏览器内存 Mock**（`frontend/src/lib/api/mock-client.ts`）：只有显式设置
  `NEXT_PUBLIC_PPT_DH_API_MODE=stage-t|production` 才走真实链，因此默认状态下刷新会丢失数据。
- 真实链已实现：`backend/app/app.ts`（Hono，仅绑 loopback）、PostgreSQL + Prisma（17 个
  migration）、transactional outbox + lease/attempt 任务模型，以及 41 个 `frontend/src/app/api/**/route.ts`
  同源 BFF。旧「没有 HTTP 服务/数据库/队列」的描述已不成立。
- `.ppt` 隔离转换已实现：上传按 OLE CFB v3/v4 头校验，PARSE attempt 内用独立 LibreOffice
  profile 转为 `source.pptx`（`backend/app/stage-11b-ppt-coverage.test.ts` 覆盖）。零页课件返回
  `PPTX_NO_SLIDES`，加密容器返回 `ENCRYPTED_PPTX`。
- 审核区已使用后端原页资产的真实 URL（`frontend/src/components/workspace/slide-preview.tsx`
  使用 `slide.originalPageUrl`），不再是"标题/摘要示意图"；但左侧站位预览与最终渲染仍不一致
  （见 `docs/planning/CURRENT_RESULTS_CAPABILITY_ROADMAP.md` 的 M3）。
- **多源页面场景当前仍可能只渲染 `sourceSlides[0]`**，不满足完整页覆盖要求（未修复项，保留）。
- 帧率与门禁分属两条链：产品链为 25/30 fps（`packages/contracts/src/render.ts`）并经过
  Stage 11F 媒体硬门；旧 CLI 原型固定 12 fps，只有基础 ffprobe/解码校验。**CLI 通过不等同于
  生产验收通过**（`DECISIONS.md` D-04）。
- 图片公式 OCR 尚未实现，但**用户已于 2026-08-04 批准延期**（`DECISIONS.md` D-27），
  图片公式保留原页并产生人工核对警告。
- 稳定资源 URL、持久任务与失败步骤重试已实现：公开投影只导出稳定 ID 与受控 URL
  （`packages/contracts/src/asset.ts` 的 `PublicAssetRefSchema`），下载支持 Range/ETag
  （`backend/app/app.ts`），重试走 `RetryTaskRequestSchema` 与稳定重试键。
- 仍然缺失的能力集中在中长期范围：对象存储/CDN、任意 PowerPoint 动画在成片中的保留
  （当前成片为静态原页）、自由布局、100 页级视频容量验证与正式供应商 SLA。
