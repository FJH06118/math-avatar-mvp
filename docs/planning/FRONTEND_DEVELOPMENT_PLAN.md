# 高等数学数字人授课智能体：开发计划

## 目标

交付一个可通过正常路由访问的中文前端 MVP，以 Mock API 演示 PPT 上传、解析、逐页讲稿编辑、数字人授课配置、视频生成进度和结果下载的完整流程。

## 视觉方向

- 产品属性：专业、可信赖、冷静高效的教育科技工作台。
- 色彩：浅灰页面背景、白色工作面、单一靛蓝主色；颜色仅用于操作与状态。
- 层级：边框和留白优先，不堆叠无意义卡片，不使用大面积渐变。
- 尺度：8px 间距节奏，12px/16px 圆角，24px–28px 页面标题，14px–16px 正文。
- 布局：首页与上传页使用居中内容容器；工作台采用桌面三栏和移动端纵向布局。

## 分阶段实施

1. 初始化 Next.js、TypeScript、Tailwind CSS、shadcn/ui、依赖和基础设计系统。
2. 在 `frontend/src/types` 定义领域类型，在 `frontend/src/lib/api` 建立带延迟、失败注入和任务进度的 Mock API。
3. 实现项目首页、最近项目加载/错误/空状态和删除确认。
4. 实现 PPT/PPTX 上传校验、上传进度、取消、失败重试和创建项目。
5. 实现 PPT 解析阶段进度、失败重试、取消和完成跳转。
6. 实现三栏项目工作台、幻灯片切换、内容 Tabs 和讲稿自动保存。
7. 使用 React Hook Form + Zod 实现数字人、声音、语速、字幕、位置和背景配置。
8. 实现生成前检查、确认弹窗、视频生成任务轮询、取消和重试。
9. 实现原生视频播放器、结果信息、MP4/SRT 下载、失败与不可用状态。
10. 完成类型检查、lint、浏览器桌面/移动端验证，并用 Web Interface Guidelines 与 UI Audit 复核和修复。
